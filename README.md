## 一、下载安装

### 1. 安装本地助手

1. 下载并**完整解压 ZIP**。
2. 双击最外层的 **「安装.command」**，按窗口提示操作，无需提前启动助手。
3. 出现 **「本地助手已连接」和「本地助手已安装」** 后，助手安装完成。

程序会安装到本应用的固定目录，并设置登录电脑后自动启动。自带运行环境不替换电脑原有的 Node.js 或 FFmpeg。

### 2. 遇到 macOS 安全拦截

首次打开安装脚本或 FFmpeg 等组件时，macOS 可能要求确认：

1. 打开 **系统设置 → 隐私与安全性**。
2. 找到对应组件的拦截提示，确认来源后点击 **「仍要打开」** 或对应允许选项。
3. 按系统提示确认，然后重新运行 **「安装.command」**。

本版尚未做 Developer ID 签名或苹果公证。若安装窗口提示「操作未完成」，请保留具体报错；通过环境检查不等于安装成功。

### 3. 加载 Chrome 扩展

1. 安装成功后，按提示进入 Chrome 扩展程序页面，也可在地址栏输入 `chrome://extensions`。
2. 开启右上角的 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择安装程序自动打开的 **extension 文件夹**。

这是安装后的固定使用位置，由安装包自动复制生成。只加载这一份，不必再加载下载包中的 extension。完成后可关闭终端窗口，助手会继续在后台运行。

## 二、首次使用配置

打开插件，点击 **齿轮「设置」**。

### 1. 验证邀请码

首次填写提供给你的插件邀请码并验证，本机会记住使用资格。退出使用或清除扩展数据后，需要重新验证。

### 2. 下载本地语音模型

在 **「语音转文字」** 中选择 **「本地 Whisper（无需 API）」**，点击 **「下载语音模型」**。

- 首次需要联网下载约 **574 MB**，等待显示 **「已就绪」** 后保存设置。
- 模型独立保存，正常更新插件和助手时会保留，无需每次下载。
- 转写在自己的电脑上完成，速度取决于 Mac 配置和音频长度。
- 模型下载后可离线转写已获取的音频；打开网页、下载平台视频仍需要网络。

如果希望使用云端服务，可切换 SiliconFlow 等服务商，填写自己的转写 API Key。

### 3. 配置 AI 整理 API（可选）

需要 AI 整理时，在 **「AI 整理 API」** 中选择服务商，填写自己的 API Key 和模型，保存后点击 **「测试 AI 连接」**。

默认提供 Gemini 配置，也支持 DeepSeek、OpenAI、千问等选项。Gemini API Key 可前往 [Google AI Studio](https://aistudio.google.com/apikey) 申请；使用资格、地区限制、免费额度及费用以服务商当前规则为准。

只提取逐字稿时，可以跳过这一步。

### 4. 检查助手连接

确认设置中的本地助手显示 **「已连接」**，保存设置后即可开始使用。

## 三、提取视频内容

1. **打开视频**：进入抖音、小红书或含视频的网页，先播放当前视频。
2. **核对识别结果**：打开插件，核对标题、作者等信息。未识别到或切换视频后，可点击 **「重新识别」**。
3. **选择所需内容**：按需设置「保存逐字稿」「AI 整理」「下载封面」「下载视频」。
4. **选择输出方式**：仅插件显示、Obsidian 或飞书。
5. **开始提取**：等待处理完成，在插件内查看和复制，或到所选笔记文件夹、飞书表格查看。

**「保存逐字稿」默认开启**，控制是否把原始文稿一并保存到笔记或表格；关闭后插件内仍可查看逐字稿。

开启 **AI 整理** 后，可以下拉选择整理规则，点击「编辑」修改，或通过「＋新增」保存不同用途的规则。规则保存在自己的浏览器中，再次使用时沿用已保存的选择。

### 输出与保存位置

| 输出方式 | 文稿 | 开启下载视频时 |
| --- | --- | --- |
| 仅插件显示 | 在插件内阅读、复制 | 保存到电脑下载目录 |
| Obsidian | 保存为 Markdown 笔记 | 保存到笔记附件目录 |
| 飞书 | 保存到自己配置的多维表格 | 上传到「视频保存」附件字段 |

**Obsidian**：先在设置中选择并授权笔记文件夹。

**飞书**：在设置中点击「获取模板」，复制到自己的飞书空间，填写自己的表格链接和个人授权码，保存并测试连接。需要保存封面时，表格中的 **「封面/笔记图片」** 应为附件类型；保存视频时，**「视频保存」** 也应为附件类型。

## 四、任务记录与问题排查

最近任务中可以查看处理状态和具体失败原因。AI 整理失败时，已生成的逐字稿会保留，修正配置后可重新整理。

| 情况 | 处理方法 |
| --- | --- |
| 助手未连接 | 运行「启动助手.command」，再到设置中检查连接 |
| 识别不到或识别错视频 | 播放当前视频，点击「重新识别」，必要时刷新网页 |
| 模型下载失败 | 检查网络后重试，等待「已就绪」再使用本地转写 |
| AI 整理失败 | 检查 Key、模型、网络、服务地区和可用额度，逐字稿仍可使用 |
| 保存权限失效 | 重新授权 Obsidian 文件夹，或检查飞书链接、授权码及字段类型 |

网页识别与下载受页面结构、登录状态及平台访问权限影响，并非所有网页视频均支持提取。请使用自己有权访问和保存的内容。

## 五、以后如何更新

下载新版安装包 → 解压并运行 **「安装.command」** → 在 Chrome 扩展程序页对插件点击 **「重新加载」**。

正常覆盖安装会保留独立存放的语音模型。日常使用无需重复安装，助手连接正常时也无需反复点击启动。
